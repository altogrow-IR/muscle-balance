# 部位バランスチェッカー

筋トレ記録アプリのバックアップJSON（`exercises` と `sets` を含む形式）を読み込んで、部位ごとのセット数の偏りと、種目ごとの次回目安を表示する、ブラウザだけで動く小さなWEBアプリです。

## 使い方

1. `index.html` をブラウザで開く（または GitHub Pages で公開したURLを開く）
2. 最初はサンプル記録が表示されます
3. 「記録JSONを読み込む」から自分のバックアップJSONを選ぶと、その場で集計し直します

データはブラウザの中だけで処理され、外部に送信されません。

## ファイル

- `index.html` / `style.css` / `app.js` — アプリ本体（ビルド不要の静的ファイル）
- `sample-data.js` — 表示確認用のサンプル記録
